# pstack paths

Read-only view of every `/poteto-mode` branch. The page parses the skill, playbook, agent, and guide files in this repo. It does not edit them.

## Run

From this directory:

```bash
npm install
npm test
npm run dev
```

Open http://localhost:5173

`npm run build` typechecks and writes a static bundle to `dist/`. `npm run preview` serves that bundle.
